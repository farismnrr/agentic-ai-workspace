## Technical references

**Observed in the project:** `go.mod` pins Fiber `v3.5.0`. `web/package.json` pins Svelte `5.57.1`, `@codemirror/merge` `6.12.2`, `@codemirror/view` `6.43.14`, and Playwright `1.63.0`. [Fiber releases](https://github.com/gofiber/fiber/releases), [Svelte releases](https://github.com/sveltejs/svelte/releases)

- **Git status and HEAD reads — AC06–AC11, AC13, AC15.** Git documents porcelain status as stable for scripts; `-z` gives NUL-delimited paths and supports safe parsing of unusual names and renames. `GIT_OPTIONAL_LOCKS=0` prevents optional lock-taking work such as status refreshing the index. The current Git adapter uses porcelain v2, a fixed Git executable and arguments, bounded time/output/file counts, and project-resolved working paths. Its metadata checks reject `.git` symlinks and selected command-capable config. These are source observations, not runtime security verification. [Git status](https://git-scm.com/docs/git-status), [Git environment and security notes](https://git-scm.com/docs/git)

- **Do not bypass `.git/FETCH_HEAD` protections.** The recorded `git fetch` failed because `.git/FETCH_HEAD` was read-only. `GIT_OPTIONAL_LOCKS=0` does not make `fetch` read-only. Do not change permissions or redirect Git’s metadata to force the fetch through. Remote-state checks and delivery belong to DevOps using the approved server-managed Git/shipping path. No callable `ship` tool was exposed in this Researcher session.

- **SSE — AC01–AC04.** EventSource reconnects using the remembered event ID when the stream provides one. That resumes transport; it does not prove ephemeral deltas were saved or reconciled. The initiative’s durable-event snapshot/order and deduplication requirements remain application-level acceptance checks. The current Fiber handler reads `Last-Event-ID` and also sends task state/events. [WHATWG Server-sent events](https://html.spec.whatwg.org/multipage/server-sent-events.html)

- **Svelte async cleanup — AC03, AC06, AC09, AC12, AC15.** `$effect` tracks synchronously read reactive values and runs teardown before rerun or component destruction. Cleanup can cancel or invalidate an older request; guarding results by selected project/request revision is a recommendation inferred from the docs and the PRD’s stale-response requirement. [Svelte `$effect`](https://svelte.dev/docs/svelte/$effect)

- **CodeMirror — AC06–AC09, AC12–AC13.** The pinned merge package provides `unifiedMergeView` with an `original` document and optional changed-line gutter. Merge controls default to enabled, so for this read-only Git feature configure them off and keep the editor read-only where appropriate. HEAD baseline and staged-plus-unstaged behavior are product requirements; the API docs do not decide that policy. [CodeMirror reference](https://codemirror.net/docs/ref/)

- **Security advisories.** The Fiber route-parameter overflow advisory is patched in `v3.1.0`; the Fiber `v3.5.0` pin is outside its affected range. The cited Svelte SSR spread-attribute XSS advisory affects versions through `5.51.4`, fixed in `5.51.5`; the `5.57.1` pin is outside that range. The PRD says the SPA is served by Go, so that SSR-specific issue does not establish exposure here. These checks do not replace a complete dependency advisory review. [Fiber advisory](https://github.com/gofiber/fiber/security/advisories/GHSA-mrq8-rjmw-wpq3), [Svelte advisory](https://github.com/sveltejs/svelte/security/advisories/GHSA-f7gr-6p89-r883)
