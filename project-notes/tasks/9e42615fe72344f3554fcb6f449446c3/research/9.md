### Technical references

**Repository facts.** The PRD requires project-scoped, read-only Git status and diffs, including staged, unstaged, renamed, deleted, untracked, conflict, unborn-HEAD, and non-Git cases. It also requires bounded outputs and protection from traversal and secret paths. Existing code already uses Svelte 5 and `@codemirror/merge`; versions pinned in the manifests are Svelte `5.57.1`, `@codemirror/merge` `6.12.2`, `@codemirror/view` `6.43.14`, Playwright `1.63.0`, and Fiber `v3.5.0` ([web/package.json](https://github.com/), [go.mod](https://github.com/)). The manifest versions are repository facts, not claims that these are the latest upstream releases.

**Git status and safe reads.** Git documents porcelain v2 as a stable machine-readable format. With `-z`, paths are NUL-delimited and unquoted; rename/copy records include a second path. Request branch headers to distinguish an unborn repository (`branch.oid (initial)`), parse unknown headers safely, and do not treat submodule changes as ordinary file edits. Ignored files are excluded by default; avoid requesting ignored entries for this UI ([git-status](https://git-scm.com/docs/git-status)).

Use a fixed executable and argument vector, repository-root working directory, `GIT_OPTIONAL_LOCKS=0`, bounded process time, and bounded stdout/stderr. Disable pager and external diff/text conversion; do not invoke a shell or interpolate paths into a revision expression. Set a narrowly scoped `safe.directory` only if ownership requires it; Git’s docs warn against `safe.directory=*` ([Git environment variables](https://git-scm.com/docs/git), [safe.directory](https://git-scm.com/docs/git-config)). For content, `git show HEAD:<path>` reads a blob from a commit, and `git diff HEAD -- <path>` compares the worktree to HEAD; validate the path as a repository-relative literal and enforce byte limits outside Git. These invocation safeguards are recommendations inferred from the PRD and Git’s documented behavior ([git-show](https://git-scm.com/docs/git-show), [git-diff](https://git-scm.com/docs/git-diff)).

**SSE resume.** EventSource automatically reconnects and sends `Last-Event-ID` when the stream has established a non-empty event ID. An `id:` field updates the remembered cursor; events without a new `id:` retain the previous ID. This is transport resume semantics, not proof that ephemeral deltas were persisted. Reconcile after reconnect against durable ordered events/snapshot, deduplicating by stable event identity and version ([WHATWG HTML, server-sent events](https://html.spec.whatwg.org/multipage/server-sent-events.html)). The repo pins its Go backend to Fiber `v3.5.0` ([go.mod](https://github.com/)).

**CodeMirror 6.** The official reference exposes `unifiedMergeView({original, gutter})` for showing a document against an original, including changed-line gutter markers. The gutter API also supports custom `GutterMarker`s. Reuse the project’s pinned `@codemirror/merge` `6.12.2` rather than introducing another editor; use a focused custom gutter only if the merge view’s markers do not fit the Git baseline semantics ([CodeMirror reference](https://codemirror.net/docs/ref/), [gutter example](https://codemirror.net/examples/gutter/)). The PRD’s HEAD baseline and staged/unstaged behavior still need an explicit, consistent product decision.

**Svelte 5 stale async results.** Svelte `$effect` reruns when synchronously read reactive dependencies change and supports teardown before rerun or component destruction. Use cleanup to cancel or invalidate an outstanding request, then guard application of its result with a request revision or selected-project identity. This stale-result pattern is an implementation recommendation inferred from the docs and PRD’s out-of-order-response requirement ([Svelte `$effect`](https://svelte.dev/docs/svelte/$effect)).

### Quality checks

Use the PRD’s black-box acceptance matrix; prioritize these checks:

- **Git status and diff:** staged only, unstaged only, both, conflict, rename with spaces/unicode, deleted, untracked, ignored, submodule, unborn HEAD, no repository, and clean-after-commit.
